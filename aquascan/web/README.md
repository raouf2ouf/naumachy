# aquascan/web

The explorer. Vite, React, TypeScript, Tailwind, TanStack Query, Recharts. Reads `aquascan/api`.

Bronze on deep water: one committed dark theme with a blue hue in the ground, one bronze accent for the claim and the interactive state, seafoam for gains and coral for losses. IBM Plex Sans with tabular figures everywhere; Plex Mono only for hashes and program bytes.

The overview is a pulse, not a wall: one claim in words with the numbers inside it, one chart with its own sentence, one strip of totals, the ranked desks as the centerpiece, three small modules, one provenance line. Every priced number carries its coverage; unpriced stays a word.

```sh
yarn workspace @naumachy/aquascan-web dev        # http://localhost:5173, proxies /api to the API on 3100
yarn workspace @naumachy/aquascan-web build      # dist/
```

Set `VITE_API_URL` when the API is not on the same origin.
