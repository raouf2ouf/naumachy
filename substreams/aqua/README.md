# naumachy-aqua

Every event of the 1inch Aqua registries, decoded: `Shipped`, `Docked`, `Pushed`, `Pulled`, each
with its block, transaction, sender and log ordinal. One map module, `map_events`, filtered by the
block index of `ethereum-common` so only blocks carrying a registry log are processed.

Aquascan reads the chains The Graph Network indexes through subgraphs (`subgraphs/aqua`, one
deployment per chain). Robinhood Chain (4663) is on The Graph only as Firehose and Substreams, so
Studio refuses a subgraph for it; this package is the road there, and Aquascan's enrichment
replays its events into the same tables the subgraphs feed. The registries share one address on
every chain, so the package runs anywhere they exist; the manifest defaults to Robinhood Chain from
the canonical registry's deployment block, 13888204.

## Build and run

```sh
substreams auth                      # once; writes SUBSTREAMS_API_TOKEN to .substreams.env
substreams build                     # protogen + cargo build --target wasm32 + pack
substreams run -e mainnet.robinhood.streamingfast.io:443 naumachy-aqua-v0.1.0.spkg map_events \
  --start-block 13888204 --stop-block +100000
```

`substreams gui` in place of `run` gives the interactive view. The Rust ABI bindings in
`src/abi/aqua.rs` and the protobuf code in `src/pb/` are generated by the build.

## Output

`naumachy.aqua.v1.Events` per block: four repeated lists, one per event kind. Each event carries a
`Ref` with `block_number`, `block_time`, `tx_hash`, `tx_from` (the taker on a settlement),
`log_index`, `ordinal` (order within the block) and `registry` (which of the two registries
emitted it). Addresses and hashes are lowercase hex with the `0x` prefix; amounts are decimal
strings in raw token units.
